# s10: Hooks（钩子机制）

`s01 > ... > s08 > s09 > [ s10 ] s11 > s12 ...`

> *"把权限检查从硬编码抽成可注册的钩子"* — 4 个事件点 + HookRegistry，扩展点不再写死。

## 问题

s09 的 `PermissionChecker` 是硬编码进 `ZQAgent` 的：每加一种检查（日志、大输出警告、统计）都要改 `ZQAgent` 主循环。一个 agent 想要审计日志，另一个想要输入重写，第三个想要工具统计 — 这些需求彼此正交，但都得改同一份循环代码。

**核心矛盾：**
- ❌ 权限、日志、统计、改写都堆在主循环里
- ❌ 加一个扩展点要改 ZQAgent 源码
- ❌ 无法按需启用/禁用功能（每次都全量编译）

## 解决方案

![Hooks Overview](/agent/hooks-overview.svg)

引入 **HookRegistry** — 把扩展点抽成 4 个固定事件，每个事件挂一串 `HookCallback`。主循环只负责在固定时机 `trigger(event, ctx)`，由注册的回调决定做什么：

```
事件点                          非-null 返回值的影响
─────────────────────────────────────────────────────────
USER_PROMPT_SUBMIT  (读入输入后)  → 用返回值替换原 prompt
PRE_TOOL_USE        (工具执行前)  → 跳过执行，返回值作为 ToolResult
POST_TOOL_USE       (工具执行后)  → 仅副作用（不影响主流程）
STOP                (本轮将退出)  → 仅副作用
```

权限检查从硬编码 if 改成 `register(PRE_TOOL_USE, new PermissionHook())`，要审计就 `register(POST_TOOL_USE, new LogHook())`，互不影响。

## 工作原理

### 1. HookEvent + HookContext — 事件枚举 + 上下文

```java
public enum HookEvent {
    USER_PROMPT_SUBMIT, PRE_TOOL_USE, POST_TOOL_USE, STOP
}

public class HookContext {
    public String userInput;       // USER_PROMPT_SUBMIT
    public String toolName;        // PRE/POST_TOOL_USE
    public String toolInput;
    public String toolResult;      // POST_TOOL_USE
    public Map<String, Object> extra = new HashMap<>();
}
```

### 2. HookCallback — 函数式接口

```java
@FunctionalInterface
public interface HookCallback {
    /** 返回非 null 表示拦截/改写；返回 null 表示仅副作用或放行。 */
    String apply(HookContext ctx);
}
```

### 3. HookRegistry — 注册 + 触发

```java
public class HookRegistry {
    private final Map<HookEvent, List<HookCallback>> hooks = new EnumMap<>(HookEvent.class);

    public void register(HookEvent event, HookCallback cb) {
        hooks.computeIfAbsent(event, k -> new ArrayList<>()).add(cb);
    }

    /** 顺序触发，返回第一个非 null 结果；全部返回 null 时返回 null。 */
    public String trigger(HookEvent event, HookContext ctx) {
        List<HookCallback> list = hooks.get(event);
        if (list == null) return null;
        for (HookCallback cb : list) {
            String result = cb.apply(ctx);
            if (result != null) return result;
        }
        return null;
    }
}
```

### 4. 内置四个钩子示例

```java
// PermissionHook：把 s09 的检查改写为 PRE_TOOL_USE 钩子
public class PermissionHook implements HookCallback {
    public String apply(HookContext ctx) {
        Decision d = PermissionChecker.check(ctx.toolName, ctx.toolInput);
        return d.type == Decision.Type.DENY
            ? "[hook 阻断] " + d.reason
            : null;
    }
}

// LogHook：所有 4 个事件都挂，打审计日志
public class LogHook implements HookCallback {
    public String apply(HookContext ctx) { /* print audit */ return null; }
}

// LargeOutputHook：POST_TOOL_USE 时检查长度
public class LargeOutputHook implements HookCallback {
    public String apply(HookContext ctx) {
        if (ctx.toolResult != null && ctx.toolResult.length() > 4000) {
            System.out.println("[warn] 输出超过 4000 字符");
        }
        return null;
    }
}

// SummaryHook：STOP 时统计本轮工具调用次数
public class SummaryHook implements HookCallback {
    public String apply(HookContext ctx) { /* print count */ return null; }
}
```

### 5. ZQAgent 集成 — 4 个事件点的触发位置

```java
// USER_PROMPT_SUBMIT
String rewritten = hookRegistry.trigger(USER_PROMPT_SUBMIT, ctxWith(userInput));
if (rewritten != null) userInput = rewritten;

while (true) {
    // ... LLM call ...
    for (ToolUseBlock use : toolUses) {
        // PRE_TOOL_USE
        String blocked = hookRegistry.trigger(PRE_TOOL_USE, ctxWith(use));
        if (blocked != null) {
            results.add(toolResult(use.id(), blocked));   // 跳过 invokeTool
            continue;
        }
        Object out = invokeTool(use.name(), input);
        // POST_TOOL_USE
        hookRegistry.trigger(POST_TOOL_USE, ctxWith(use, out));
        results.add(toolResult(use.id(), out));
    }
    if (stopReason != "tool_use") {
        hookRegistry.trigger(STOP, ctx);
        return;
    }
}
```

## 相对 s09 的变更

| 组件 | s09 | s10 |
|------|-----|-----|
| 权限检查 | 硬编码进 ZQAgent | 改写成 PRE_TOOL_USE 钩子，可插拔 |
| 扩展点 | 改源码 | 4 个事件 × N 个回调 |
| 新增类 | — | HookEvent、HookContext、HookCallback、HookRegistry + 4 个内置钩子 |
| 可组合性 | 一份代码一种行为 | 同一份代码按需挂不同钩子组合 |

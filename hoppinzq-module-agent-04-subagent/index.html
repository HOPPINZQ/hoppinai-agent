Core Components

核心组件

三大组件构成强大的智能体系统

🧠
Agent04（主智能体）
任务协调者 & 管理者

作为系统的核心大脑，负责理解用户需求、分析任务复杂度， 并通过强大的工具集协调整个工作流程。

🛠️ bash 📄 read_file ✏️ write_file 📝 edit_file 📂 glob 🔍 content_search ✅ todo 🤖 sub_agent
  • ✦ 管理最多 20 个待办事项，同时仅 1 个进行中
  • ✦ 可将复杂任务委托给子智能体处理
  • ✦ 3 回合未更新待办事项会收到提醒
⚡
SubAgent（子智能体）
具体任务的执行者

专注于执行主智能体分配的具体任务，轻量化设计， 从空上下文开始独立运行，高效完成目标。

📄 read_file ✏️ write_file 📝 edit_file
  • ✦ 仅有 3 个文件操作工具，专注执行
  • ✦ 无 sub_agent 工具，防止递归委托
  • ✦ 从空的 messages[] 开始独立消息循环
  • ✦ 仅返回摘要文本 + Token 使用统计
🏗️
ZQAgent（基类）
所有智能体的基类

提供所有智能体共享的基础设施，封装了消息循环、 工具调用和会话管理等核心能力。

  • ✦ 处理消息循环 & 工具调用
  • ✦ 支持会话持久化（JSON 格式存储）
  • ✦ 支持历史会话恢复
  • ✦ 提供 runTask() 和 runTaskWithTokenUsage() 方法
How It Works

工作流程

从任务接收到底层执行，环环相扣的自动化流水线

1
📥

任务接收与分析

主智能体仔细理解用户需求，深入分析任务复杂度，制定最佳执行策略。

2
📋

待办事项管理

创建或更新任务列表，为每个子任务设置合理状态：pending、in_progress、completed。

3
⚖️

任务执行策略

简单任务：主智能体直接使用工具完成。
复杂任务：分解为子任务，使用 sub_agent 委托给子智能体。

4
📊

进度跟踪

定期更新待办事项状态，任务完成后标记为 completed，3回合未更新则提醒。

Tools Reference

工具列表

主智能体与子智能体各自拥有的工具能力

工具名称 描述 所属
bash 执行 Shell 命令，与操作系统交互 🧠 主智能体
read_file 读取指定文件的完整内容 🤝 通用
write_file 创建或覆盖写入文件内容 🤝 通用
edit_file 基于搜索替换方式编辑文本文件 🤝 通用
glob 列出指定目录下的文件和子目录 🧠 主智能体
content_search 使用 ripgrep 在文件中搜索内容 🧠 主智能体
todo 待办事项管理（创建/更新/查询） 🧠 主智能体
sub_agent 将复杂任务委托给子智能体执行 🧠 主智能体

项目简介

Project Overview

Agent06 是 HoppinAI Agent 系列 第六号模块，专注解决 LLM 长对话中的 上下文窗口溢出 问题。基于 Java 17 + Anthropic 消息协议构建， 核心是一套精巧的 四层渐进式压缩策略（L1→L4），层层递进、按需触发。

核心设计哲学："Cheap First, Expensive Last" —— 先用免费手段压缩， 万不得已才调用 LLM 生成摘要。在保证对话质量的前提下，最大限度地降低 Token 消耗。

四层渐进式压缩

Core Innovation
✂️ snipCompact · 中间裁剪 免费

裁剪中间不重要的消息，只保留头部（系统提示）和尾部（最近交互）。

策略：保留 System + 最近的 User/Assistant 交互，删除中间冗余轮次。snipRatio 默认 0.6。
🔇 microCompact · 工具结果精简 免费

将旧的工具执行结果替换为精简的占位符标记，大幅减少文本量。

策略：冗长输出替换为 [已执行: 工具名]。保留最后 2 条原始结果。
💾 toolResultBudget · 超大结果转磁盘 免费

超大工具结果写入本地磁盘文件，仅保留文件引用在上下文中。

策略：超过 2000 token 的结果写入 compact_tool_results/ 目录。
🤖 autoCompact · LLM 智能摘要 1 次调用

调用 LLM 自动生成对话摘要，替换历史对话内容。最后一道防线。

策略：用 <compacted></compacted> 标签生成结构化摘要，压缩率极高。
压缩触发机制：每次消息循环前自动检测上下文长度，按超出程度决定执行哪一层。 支持 /compact 命令或 compact 工具手动触发。 所有压缩记录存储在 TranscriptRecord 中，可通过 /transcripts 查看。
